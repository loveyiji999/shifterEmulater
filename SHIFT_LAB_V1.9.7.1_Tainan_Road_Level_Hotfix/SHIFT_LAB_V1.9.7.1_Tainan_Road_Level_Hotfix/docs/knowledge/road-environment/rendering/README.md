# 路面邊坡與山體渲染知識庫

更新：2026-10-28。依使用者決定，優先完成環境渲染及所見即所得的基礎，再考慮賽事流程。本輪補充渲染技術、選型依據與驗證計畫；尚未修改遊戲或宣稱達到特定FPS。

## 目標

玩家能辨識各種路面、坡地與山體，看到的可通行區域、障礙、孔洞及坡度應與實際接觸一致。在此條件下，以指定硬體和瀏覽器的實測結果，選取能穩定運行的最高畫質組合。

「最好效能」以同一場景下的幀時間、卡頓、解析度、畫質與記憶體比較，不能由WebGPU名稱、面數或貼圖解析度單獨判定。參考[WebGL效能原則](sources/WEBGL-PRACTICES.md)及[GPU計時規格](sources/GPU-TIMER.md)。
