## Local real-3D acceptance (required before declaring stable)

From `desktop3d/` run `npm install` and `npm run dev`. In a separate terminal at the project root:

```sh
python desktop3d/tests/browser_v1893.py --url http://127.0.0.1:5173/ --drive-seconds 10 --map-rebuilds 3
python desktop3d/tests/browser_v1893.py --url http://127.0.0.1:5173/ --drive-seconds 1800 --map-rebuilds 10
```

The first run requires real WebGL and Rapier and checks P/R/N/D, refusal of unsafe shifts, manual isolation, seeded maps and five physics QA scenarios. The second measures continuous drive. The test script writes `desktop3d/tests/artifacts/v1893_browser_report.json` and screenshots on failure.

## Player manual acceptance checklist

1. Open web game: start in P (gear instrument P, PRND buttons visible). Release foot brake and apply throttle: the car must not launch.
2. Tap R without holding the brake: it must be rejected with a temporary warning.
3. Hold S and select R (button, setting selector when paused, or R key): wait for original reverse synchronizer; on W throttle move backward. Gear instrument reads R when engaged.
4. While moving backward, attempt P then D: both must be rejected. N is allowed; press S to stop.
5. Hold S, select D (button or F), release brake, accelerate and verify 1->2->3 shifting. Stop and select P. P should keep car stationary on a normal slope.
6. Switch to manual (M) and test clutch Shift + R, Shift + 1, Shift + 0 with original interlocks. Automatic PRND controls must disappear in manual.
7. Repeat after regenerating maps and after switching car types. Test each of the five Rapier QA scenarios in Test mode.
8. Verify both keyboard controls and a physical gamepad; report non-finite values, sliding in P, clutch stalls and wheel force anomalies.

## Known limitations

The parking brake applies physical wheel brake torque through the four-wheel model; it is NOT a detailed internal transmission parking pawl. A low-grip road can still allow locked-wheel sliding. The automatic range is a control layer around an AMT gearbox, not a torque-converter/planetary automatic.
