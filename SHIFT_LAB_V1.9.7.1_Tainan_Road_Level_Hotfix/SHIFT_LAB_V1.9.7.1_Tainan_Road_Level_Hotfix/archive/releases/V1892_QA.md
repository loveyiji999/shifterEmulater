## Required runtime verification on local machine

1. Extract ZIP and run `START_WEB_WINDOWS.cmd`, or `sh START_WEB_UNIX.sh`. Internet is required the first time to install npm dependencies.
2. Open `http://127.0.0.1:5173/` and check WebGL2/Rapier boot with no full-screen error.
3. In Settings, choose diesel; check vehicle is reset and playable. Switch to Manual, park, choose first gear; confirm the original synchronizer engages. Switch back to automatic and confirm Shift + 1/6/R does not manually change gear.
4. In Settings, regenerate several maps, enter Tests, return to Free Drive; confirm original selected seed is restored and there are no stale collisions.
5. Run `python desktop3d/tests/browser_v1892.py` while Vite is running. Script checks real WebGL boot, keyboard, automatic isolation, parked manual shift, map rebuilding, and the full five-case Rapier acceptance suite.
6. Run the endurance probe: `python desktop3d/tests/browser_v1892.py --drive-seconds 1800 --map-rebuilds 10`. Confirm no non-finite values, crashes, or unbounded memory growth. Repeat with actual keyboard and physical controller, not only headless Chromium.
7. In `desktop3d`, run `npm run build`; deploy the **contents of dist/** to an HTTPS host and repeat smoke tests against the published URL.

**Acceptance criterion:** The 5 native 3D tests must all PASS, with 30 minutes of normal driving and repeated road changes without irrecoverable faults. This gate is pending, not waived.
